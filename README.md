Logistics -  Website

A high-performance, premium web application for **Ashtam Global Logistics**, specializing in heavy hauling, ODC cargo, and international freight solutions.

## 🚀 Key Features
- **Modern UI/UX:** High-fidelity design with a premium navy and gold aesthetic.
- **Fully Responsive:** Optimized for desktops, tablets, and mobile devices.
- **Interactive Map:** Integrated Mapbox GL JS for real-time office location tracking on the Contact page.
- **Service Specialization:** Dedicated pages for International Freight, Transformer Logistics, Contract Logistics, and more.
- **High-Impact Sections:** Custom-built "Why Choose Us" sections with interactive cards and high-resolution graphics.
- **Performance Optimized:** Clean HTML5, Vanilla CSS3, and lightweight JavaScript.

## 🛠️ Technologies Used
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Frameworks:** Bootstrap 5 (for grid and base components)
- **Maps:** Mapbox GL JS
- **Icons:** FontAwesome 6
- **Fonts:** Google Fonts (Inter, Roboto)

## 📁 Project Structure
- `index.html` - Homepage
- `about.html` - Company history and mission
- `services.html` - Overview of logistics services
- `projects.html` - Portfolio of completed logistics projects
- `industries.html` - Sector-specific solutions
- `contact.html` - Interactive contact form and Mapbox integration
- `css/style.css` - Custom premium styling
- `js/script.js` - Global interactive logic
